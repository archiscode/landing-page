# Freelance Landing Page

A responsive one-page website for a freelance developer. Plain HTML, CSS and JavaScript, no build step, no dependencies.

## Features
- Interactive hero demo: a messy folder that sorts itself (animated with the Web Animations API)
- Contact form with accessible validation (inline errors, focus on the first error)
- Automatic dark mode (`prefers-color-scheme`)
- Mobile-first responsive layout, keyboard focus styles, skip link and reduced-motion support

## Before you publish: replace these placeholders
1. `Your Name` in `index.html` (title, header, footer)
2. `YOUR-USERNAME` in every GitHub and LinkedIn link
3. `CONTACT_EMAIL` at the top of the form section in `script.js`

## Run locally
Open `index.html` in your browser.

## Publish free with GitHub Pages
1. Push the repository to GitHub.
2. Open **Settings > Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then save.
4. Your site appears at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Tech
HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript
